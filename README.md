## Overview

Guitar Rack Tuner is a chromatic tuning application designed for guitar and bass players, featuring a professional rack-style interface.

Designed for musicians, home studios and recording environments.

## Main Features

- Real-time chromatic tuning
- Guitar and bass support
- High-precision frequency detection
- Adjustable reference frequency
- Input gain control
- Audio input device selection
- Professional rack-style interface
- Real-time tuning indicators
- External audio interface support
- Windows and macOS versions

## Getting Started

1. Download and install the application.
2. Connect your guitar or bass to your audio interface.
3. Select the appropriate audio input device.
4. Adjust the input gain.
5. Press Start and begin tuning.

## System Compatibility

- Windows 10 / 11
- macOS
- Compatible audio input device
